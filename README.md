OOP PROJECT - Hospital Management System MediCore

How to compile: 
1) Open OOP PROJECT.sln in Visual Studio 2022.
2) Make sure the these files are there with the sln file.
3) make sure that sfml 2.6.1 is integrated in your visual studio and sfml files are there in the project files.
4) Press F5 and Run.
5) login as patient, doctor or admin.

Git hub repository: https://github.com/RayyanFurqan/MediCore-HMS
